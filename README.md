# ⚡ ALEMBIC STORE BOT | @alembic_store_bot⚡
###🏁 Если запущен на сервере, то функционирует\n
**Высокопроизводительный Telegram-бот для автоматизированной продажи цифровых товаров с ИИ-модерацией отзывов и Docker-контейнеризацией.**

## 🌟 Ключевые особенности

### 🧠 Умная ИИ-модерация отзывов (Smart AI Review Pipeline)

> **Революционный подход к репутации шопа:** бот интегрирован с современными нейросетевыми алгоритмами для мгновенной валидации входящих отзывов клиентов.

* **Автоматический семантический и тональный анализ:** ИИ считывает реальный контекст отзыва, отсеивая спам, токсичность, рекламу конкурентов и нерелевантные сообщения.

* **Автопубликация:** Если отзыв положительный и конструктивный — он моментально транслируется в публичный канал с отзывами.

* **Антикризисный маршрутизатор:** При обнаружении негатива, спорного инцидента или технической претензии, ИИ мягко перенаправляет клиента в саппорт с прямой ссылкой на оператора для быстрого решения вопроса без ущерба для публичного канала.

### 🛒 Клиентский интерфейс & Покупки

* **Каталог товаров:** Удобная навигация по категориям и карточкам товаров.

* **Интерактивные медиа:** Просмотр фотографий и превью товаров по клику на инлайн-кнопку без засорения диалога.

* **Умная выдача заказов:**

  * До 5 позиций — вывод товара в текстовом сообщении.

  * **Массовая покупка (> 5 позиций)** — автоматическая генерация и отправка аккуратного `.txt` файла с купленными позициями.

* **Шлюзы пополнения баланса:**

  * **CryptoBot** (криптовалюты).

  * **Platega** (банковские карты, СБП, альтернативные методы).

* **Служба заботы:** Инлайн-кнопка для моментальной связи с поддержкой.

### 👑 Панель администратора (Admin Panel)

Комплексный инструмент для полного контроля над магазином прямо из Telegram:

* **Управление каталогом:**

  * Добавление, редактирование, скрытие и удаление позиций.

  * **Пакетная загрузка:** Массовый залив позиций простым отправлением `.txt` файла.

* **CRM и работа с аудиторией:**

  * Поиск пользователей и просмотр истории их заказов по `Telegram ID` или `@username`.

  * Ручное пополнение/списание баланса пользователя.

  * Блокировка (бан) нарушителей.

  * Механизм мгновенных возвратов средств на баланс.

* **Маркетинг и лояльность:**

  * Конструктор промокодов (на фиксированную сумму или процент).

  * Таргетированные и массовые рассылки сообщений с медиа.

  * Обязательная проверка подписки (OP) на целевой канал перед началом работы с ботом.

* **Аналитика и безопасность:**

  * Детальная статистика продаж, выручки и конверсий.

  * **Тумблер техработ:** Переключение бота в режим обслуживания одной кнопкой с уведомлением пользователей.

## 🛠 Стек технологий

* **Ядро:** Python 3.12 + [Aiogram 3.x](https://github.com/aiogram/aiogram) (асинхронная архитектура)

* **Инфраструктура:** Docker & Docker Compose

* **База данных:** SQLAlchemy + SQLite

* **Платежные системы:** CryptoPay API, Platega API

* **ИИ-интеграция:** LLM API (OpenAI / OpenCode Free)



## 📁 Структура проекта

```
├── handlers/              # Обработчики команд и инлайн-кнопок (каталог, админка, отзывы)
├── keyboards/             # Клавиатуры и инлайн-разметка меню
├── middlewares/           # Проверка подписки, фильтрация техработ
├── services/              # Бизнес-логика: платежи, генерация файлов, AI-клиент
├── database/              # Модели ORM, миграции и запросы к БД
├── data/                  # Хранилище SQLite базы, картинок и файлов
├── .env.example           # Шаблон конфигурации
├── Dockerfile             # Сборка контейнера
├── docker-compose.yml     # Оркестрация сервисов
└── main.py                # Точка входа в приложение

```
